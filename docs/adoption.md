# 観点ごとの採択率

<!-- harness accumulate が data/history.jsonl から生成 -->

採択率 = 採択 /（採択 + 不採択）。5 件以上の観点で 30% 未満は見直し候補（⚠）です。
観点の書き方か「無効となるケース」が足りず、誤指摘が多い可能性があります。

| check_id | 観点 | 採択 | 不採択 | 採択率 | |
|---|---|---|---|---|---|
| ALL-003 | 「など」「適宜」「必要に応じて」で範囲がぼかされていない | 1 | 0 | 100% |  |
| API-007 | 参照・更新するテーブルと条件が書かれている | 0 | 1 | 0% |  |
| NEW | （新しい観点） | 1 | 0 | 100% |  |
