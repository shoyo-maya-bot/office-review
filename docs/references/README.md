# 判断基準の資料（references）

レビューで「何に照らして」判断するかの資料を置きます。レビュー対象（`inputs/`）とは混ぜません。

| 置くもの | 例 |
|---|---|
| 社内標準・規約 | API 設計標準、命名規約、メッセージ規約、セキュリティ基準 |
| 上位文書 | 要件定義書、基本設計書の共通部分（Markdown にしたもの） |
| 外部仕様 | 連携先システムの API 仕様 |
| 用語集 | 業務用語・略語と、使ってはいけない言い換え |

> 公開リポジトリに置く場合は、社外秘の資料を入れないでください。実案件では会社の GitHub に複製してから置きます。
