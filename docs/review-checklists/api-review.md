指摘は「無効となるケース」に当たらないことを確かめてから出します。重要度は既定値で、状況に応じて変えてかまいません。

## アーキテクト（architect）— 責務分担・方式・再利用・拡張性

| ID | 分類 | 既定の重要度 | 観点 | 確かめること | 無効となるケース |
|---|---|---|---|---|---|
| ALL-005 | 整合性 | MUST | 上位文書（要件定義・基本設計）と矛盾していない | 機能・項目・条件が上位文書の記載と一致している。差異がある場合は理由と上位文書の修正依頼がある | 上位文書の改版が承認済みで、本書がその改版に追随している場合 |
| API-004 | 冪等性 | MUST | 更新系 API の再送時の動きが決まっている | POST / PUT / DELETE がタイムアウト等で再送されたとき、二重登録・二重更新にならない方式（冪等キー・一意制約など）が書かれている | 参照系（GET）のみの API |

## インフラ（infra）— 性能・可用性・セキュリティ・ネットワーク

| ID | 分類 | 既定の重要度 | 観点 | 確かめること | 無効となるケース |
|---|---|---|---|---|---|
| API-005 | 性能 | WANT | 想定件数・応答時間・同時実行数がある | 1 回あたりの最大件数、目標応答時間、ピーク時の同時リクエスト数が書かれている | 非機能要件書で API 共通の値として定義され、その参照がある場合 |
| API-006 | セキュリティ | MUST | 認可（誰がどのデータにアクセスできるか）が書かれている | 他人のデータを ID 指定で取得できないなど、リソース単位の認可条件が書かれている | 認証不要で公開して問題ない情報だけを返す API（その旨が明記されていること） |

## 仕様管理（spec_manager）— 業務要件との整合・記載の網羅と一貫性

| ID | 分類 | 既定の重要度 | 観点 | 確かめること | 無効となるケース |
|---|---|---|---|---|---|
| ALL-001 🤖 | 文書管理 | MUST | 文書 ID・版・承認状態が明記されている | Front Matter（または表紙）に id・版数・status があり、改版履歴が最新版と一致している | 作成途中のドラフトで、レビュー依頼の時点で status を draft と明示している場合 |
| ALL-002 | 用語 | WANT | 用語が用語集と一致し、同じものを別の言葉で呼んでいない | 同じ概念に複数の呼び方（例「会員」「ユーザー」）が混在していない。用語集（docs/references/）にある語を使っている | 引用した外部仕様の原文表記をそのまま残している場合（引用である旨が書かれていること） |
| ALL-003 | 記載の明確さ | MUST | 「など」「適宜」「必要に応じて」で範囲がぼかされていない | 処理対象・条件・値の範囲が列挙または条件式で確定している | 例示であることが明記され、確定した一覧が別の箇所にある場合 |
| ALL-004 | 未決事項 | MUST | 未決事項（TBD・要確認）が一覧化され、期限と担当がある | 本文中の TBD・要確認・検討中が、未決事項表に期限と担当付きで載っている | 該当工程の対象外と明記して次工程に送っている場合 |
| API-001 🤖 | インタフェース | MUST | API ID・メソッド・パス・認証要否が一覧にある | 各 API について ID、HTTP メソッド、パス、認証の要否が表で定義されている | なし |
| API-002 🤖 | 入力定義 | MUST | 入力項目に必須・型・桁・形式・前処理がある | 入力項目表に「必須」「形式（型）」「桁」があり、前後空白の除去や大文字小文字の扱いなど前処理が書かれている | 入力の無い API（パラメータなしの照会など） |
| API-003 | 応答定義 | MUST | 結果ごとの HTTP ステータスとメッセージ ID が定義されている | 正常・入力誤り・該当なし・業務エラー・システムエラーのそれぞれに、ステータスとメッセージ ID がある | 共通のエラー仕様書に委ねると明記し、その文書を参照している場合 |

| ID | 分類 | 既定の重要度 | 観点 | 確かめること | 無効となるケース |
|---|---|---|---|---|---|
| API-007 | データアクセス | WANT | 参照・更新するテーブルと条件が書かれている | CRUD 表または処理手順に、テーブル名・操作・検索条件・ロックの要否がある | 外部システムへの中継だけで DB を使わない API |
