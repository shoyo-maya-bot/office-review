# ロール: インフラ（infra）

**見るところ**: 性能・可用性・セキュリティ・ネットワーク。件数と時間の見積もり、障害時の振る舞い、認証・認可・暗号化

## レビューのしかた

1. `docs/review-checklists/<種別>-review.md` のうち、ロールが infra の観点を上から順に確かめる
2. 観点ごとに「無効となるケース」に当たらないかを先に確かめる
3. チェックリストに無いが、このロールとして問題だと思う点は check_id を **NEW** にして指摘する（後で観点の追加候補になる）
4. 他のロールの観点には踏み込まない（重複指摘を避ける）。気づいた場合は Q で他ロールに渡す
