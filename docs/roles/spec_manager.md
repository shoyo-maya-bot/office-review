# ロール: 仕様管理（spec_manager）

**見るところ**: 業務要件・上位文書との整合、記載の網羅性と一貫性、用語、未決事項の管理

## レビューのしかた

1. `docs/review-checklists/<種別>-review.md` のうち、ロールが spec_manager の観点を上から順に確かめる
2. 観点ごとに「無効となるケース」に当たらないかを先に確かめる
3. チェックリストに無いが、このロールとして問題だと思う点は check_id を **NEW** にして指摘する（後で観点の追加候補になる）
4. 他のロールの観点には踏み込まない（重複指摘を避ける）。気づいた場合は Q で他ロールに渡す
