# 注文照会 API（API0101）

## 1. 概要

| API ID | メソッド | パス | 認証 | 内容 |
|---|---|---|---|---|
| API0101 | GET | `/api/v1/orders` | 要（会員ログイン） | 会員の注文を一覧で返す |

## 2. 入力

| 項目 | 必須 | 形式 | 桁 |
|---|---|---|---|
| memberId | ○ | 数値 | 10 |
| from | | 日付（YYYY-MM-DD） | 10 |

## 3. 処理

1. memberId の注文を、注文日の新しい順に取得する
2. from があれば、その日以降に絞り込む
3. 件数が多い場合は適宜ページングする

## 4. 出力

200 で注文の一覧を返す。エラー時は共通のエラー応答を返す。
